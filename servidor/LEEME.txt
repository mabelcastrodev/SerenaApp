======================================================
 SERENA - BASE DE DATOS Y SERVICIOS (AlwaysData)
======================================================

Esta carpeta NO es parte de la app Android. Son los archivos
que van en el hosting, dentro de:  /home/mabelcastro/www/serena/

Archivos:
  serena.sql               -> crea las 2 tablas con 6 categorias y
                              33 sesiones (BORRA lo que habia)
  actualizar_imagenes.sql  -> solo agrega la columna "imagen" a una
                              base que ya tiene datos (NO borra nada)
  conexion.php             -> plantilla de conexion (ver abajo)
  categorias.php           -> servicio JSON de categorias
  meditaciones.php         -> servicio JSON de sesiones
                              ?idcategoria=N   solo esa categoria
                              ?idmeditacion=N  solo esa sesion
  imagenes/                -> c1..c6.jpg y m1..m33.jpg


------------------------------------------------------
 PASOS PARA LA PA3
------------------------------------------------------
1. phpMyAdmin de AlwaysData -> tu base -> pestana SQL:
   - Si tu base ya tiene las 33 sesiones: ejecuta
     actualizar_imagenes.sql
   - Si quieres empezar de cero: importa serena.sql

2. FileZilla (ftp-mabelcastro.alwaysdata.net):
   sube categorias.php, meditaciones.php y la carpeta
   imagenes/ completa a www/serena/

   OJO: NO subas este conexion.php. El del servidor ya tiene
   tu usuario y clave reales de AlwaysData; este solo tiene
   los datos de ejemplo de XAMPP.

3. Prueba en el navegador:
   https://mabelcastro.alwaysdata.net/serena/categorias.php
   https://mabelcastro.alwaysdata.net/serena/meditaciones.php?idmeditacion=1
   https://mabelcastro.alwaysdata.net/serena/imagenes/categorias/c1.jpg

   Cada fila tiene que traer "imagen":"imagenes/...".


------------------------------------------------------
 EN LA APP
------------------------------------------------------
La direccion del servidor esta en:
  app/src/main/java/com/mabel/serenaapp/data/remote/RetrofitClient.kt

  const val BASE_URL = "https://mabelcastro.alwaysdata.net/serena/"

La app arma la URL de cada imagen como BASE_URL + imagen.
Si una fila no tiene imagen, la app muestra img_placeholder.
